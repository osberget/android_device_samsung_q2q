Samsung Galaxy Z Fold3 5G SM-F926B q2q

LineageOS 24.0 (Android 17) device tree for the European Samsung Galaxy Z Fold3 5G SM-F926B.

This device tree runs LineageOS 24.0 on top of the stock Android 15 (F926BXXSJJZH3) vendor partition using a patched stock vendor_boot.img. (you can find it in releases)



Device Specifications

Samsung Galaxy Z Fold3 5G SM-F926B EUX q2q

Kernel 5.4.274 with stock boot.img vendor.img and patched vendor_boot.img
based on Stock Base F926BXXSJJZH3 A15



What Works

- Boots into LineageOS 24.0 (Android 17)
- Inner foldable display and outer cover display
- Wi-Fi, Bluetooth, and mobile data / calls
- Speaker (maybe, cant test my speakers don't work), microphone, and Bluetooth audio
- Sensors, vibration, and USB
